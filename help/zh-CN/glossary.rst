轴向长度
------------

轴向长度是光束在元件内部走过的几何距离。在大多数情况下，它与元件的 Length 参数值相同。但有些元件（例如 :doc:`matrix/ElemTiltedPlate`）则不同，因为它们的长度通常是从一端到另一端测量的，而光束以某个角度相对于该方向通过，走过的距离更大。

    .. image:: img/axial_len.png

.. _propagation_dir:
.. index:: single: propagation direction

传播方向
---------------------

|rezonator| 假设光束在光路中从左向右传播。对于 :ref:`单程 <schema_kind_sp>` 光路，就好像光源位于光路最左侧元件的正前方，并指向右侧。

    .. image:: img/propagation_sp.png

对于 :ref:`谐振腔 <schema_kind_rr>`，这只是所选的主方向。在 :ref:`驻波谐振腔 <schema_kind_sw>` 中，光束从最右侧的元件反射并完成往返，回到最左侧的元件。

    .. image:: img/propagation_res.png

当计算 :doc:`往返矩阵 <round_trip_matrix>` 时，元件矩阵从某个参考元件开始、沿与光束传播相反的方向相乘，正如光线矩阵方法所假设的那样。

光线矢量
----------

光线矢量表示光束的一种几何近似，其中光束由两个参数描述——距光轴的距离 `r` 和光束与光轴之间的夹角 `V`。

    .. image:: img/ray_vector.png

当光束穿过一个光学系统时，输出光束的参数可以由输入光束的参数和系统的光线矩阵 `M = [A, B; C, D]` 表示出来。

    .. image:: img/ray_vector_1.png

|rezonator| 可以计算 :ref:`单程 <schema_kind_sp>` 光路中的光线矢量传播，见 :ref:`Pump mode: Ray vector <pump_mode_vector>`。

约化斜率
-------------

在定义 :ref:`光线矢量 <ray_vector>` 时，有些资料使用所谓的“约化斜率”，而不是光线与光轴之间的几何夹角。这时角度要乘以测量光线所在介质的折射率：`r' = n * dr/dz`，其中 `z` 是沿光轴的距离。这种方法可以简化某些矩阵；例如，:ref:`法向界面 <ElemNormalInterface>` 将具有单位矩阵。但这只在输入和输出参考平面处于不同介质时（对于界面元件）才有区别。此外，这种方法在显示计算结果时似乎不太实用——要显示光线角度，我们必须始终记住介质的折射率。因此 |rezonator| 对光线矢量使用几何角度 `V ~ tg V = dr/dz`，所有元件矩阵也据此定义。

稳定性参数
-------------------

稳定性参数是一个表明系统能否支持稳定激光运行的值。它可以用两种方式计算：

* `P = (A + D) / 2`
* `P = 1 — ((A + D) / 2)` :sup:`2`

其中 A 和 D 是系统 :ref:`往返矩阵 <round_trip>` 的分量。在第一种情况下，当参数值在 -1 到 1 的范围内时系统稳定。在第二种情况下，当参数值在 0 到 1 的范围内时系统稳定。

工作平面
--------------

**切向平面，T 平面**

切向平面是包含谐振腔所有元件的平面（光学平台的平面）。光束在这个平面内折射或反射。

**弧矢平面，S 平面**

弧矢平面是包含元件光轴并垂直于切向平面的平面。
