Menu Edit
---------

.. --------------------------------------------------------------------------

.. _plot_opers_copy_graph:

复制图形数据
~~~~~~~~~~~~~~~

:menuSelection:`Edit --> Copy Graph Data...`

该命令打开一个对话框，用于将图形数据导出到剪贴板。你可以选择要导出的内容和目标格式。它是图形上下文菜单中提供的 :ref:`plot_opers_copy_graph_ctx` 命令的进阶版本。

.. --------------------------------------------------------------------------

.. _plot_opers_copy_image:

复制图图像
~~~~~~~~~~~~~~~

:menuSelection:`Edit --> Copy Plot Image`

该命令将当前图作为图像复制到剪贴板。默认情况下，光标线也会作为图像的一部分被复制，但这可以通过 :ref:`应用选项 <app_settings_export_hide_cursor>` 覆盖。该命令也可以在图的 :ref:`上下文菜单 <plot_opers_copy_image_ctx>` 中使用。

Menu Plot
---------

.. --------------------------------------------------------------------------

更新
~~~~~~

:menuSelection:`Plot --> Update (F5)`

该命令重新计算函数。所有图形、特殊点和光标值都会更新。如果当前函数已 :ref:`冻结 <func_freeze>`，则该命令不可用。

.. --------------------------------------------------------------------------

带参数更新
~~~~~~~~~~~~~~~~~~~~~~

:menuSelection:`Plot --> Update With Params (Ctrl+F5)`

该命令与 Update 命令的作用相同，但在函数被重新计算之前，你可以为函数指定新的参数。但并非所有参数都可以更改。特别是，你不能更改函数的可变参数。但可以更改所得图形中的点数或它们的范围。

.. --------------------------------------------------------------------------

冻结
~~~~~~

:menuSelection:`Plot --> Freeze (Ctrl+F)`

该命令冻结当前绘图窗口。详情见 :doc:`func_freeze`。

.. --------------------------------------------------------------------------

TS 翻转模式
~~~~~~~~~~~~~~~

:menuSelection:`Plot --> TS-Flipped Mode`

如果该选项打开，则 S 图形会以竖直镜像方式显示。

  .. image:: img/plot_opers_flip_ts.png

.. --------------------------------------------------------------------------

显示 T 平面
~~~~~~~~~~~~

:menuSelection:`Plot --> Show T-plane`

该命令切换切向 (T) 平面图形的可见性。

  .. note::
    其中一个图形（T 平面或 S 平面的）始终保持可见。这意味着如果其中一个图形被隐藏，而你试图隐藏另一个，那么第一个会变为可见。

.. --------------------------------------------------------------------------

显示 S 平面
~~~~~~~~~~~~

:menuSelection:`Plot --> Show S-plane`

该命令切换弧矢 (S) 平面图形的可见性。

  .. note::
    其中一个图形（T 平面或 S 平面的）始终保持可见。这意味着如果其中一个图形被隐藏，而你试图隐藏另一个，那么第一个会变为可见。

.. _plot_opers_copy_graph_ctx:

复制图形数据
~~~~~~~~~~~~~~~

:menuSelection:`Context menu --> Copy Graph Data`

:menuSelection:`Context menu --> Copy Graph Data (this segment)`

:menuSelection:`Context menu --> Copy Graph Data (all segments)`

该命令使用默认的 :ref:`导出设置 <app_settings_export_opts>` 将图形值导出到剪贴板。对于像 :doc:`func_caustic_mr` 这样将图形拆分为多个区段的函数，可以将所有区段作为一个数据块复制，或只复制当前选中的区段。该命令有一个 :ref:`进阶版本 <plot_opers_copy_graph>`，允许你通过对话框控制所有导出设置。
