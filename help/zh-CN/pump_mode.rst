.. index:: single: pump mode

泵浦模式
=========

:menuSelection:`Windows --> Pumps --> Pump --> Create (Ctrl+Ins)`

对于 SP 光路，你可以用几种方式指定输入光束的参数。

  .. image:: img/select_pump_mode.png


.. _pump_mode_waist:

束腰
-----

在这种模式下，你可以指定束腰半径，以及束腰到光路第一个元件的距离。

利用这些参数和给定的 M² 值，可以计算出等效高斯光束在光路第一个元件处的束腰半径和波前曲率半径。然后计算等效高斯光束的复曲率半径，再由光路矩阵对它进行变换。

  .. image:: img/pump_waist.png


.. _pump_mode_front:

波前
-----

在这种模式下，你可以指定输入光束在光路第一个元件处的半径和波前曲率。

利用这些参数和给定的 M² 值，可以计算等效高斯光束的复曲率半径。然后由光路矩阵对它进行变换。

  .. image:: img/pump_front.png


.. _pump_mode_vector:

光线矢量
----------

在这种模式下，你可以指定输入光束在光路第一个元件处的半径和发散角的一半。

在这种情况下不计算复曲率半径，也不考虑 M² 参数。光束按几何方法处理，而不是作为高斯光束处理。

  .. image:: img/pump_ray.png


.. _pump_mode_sections:

两个截面
------------

这种方法与 “Ray vector” 相同。但是，你不用设置发散角，而是可以指定两个截面的半径以及它们之间的距离，发散角由此计算得出。光束同样按几何方法处理。

  .. image:: img/pump_sects.png


.. _pump_mode_complex:

复数或复数倒数
--------------------------

在这种模式下，你可以指定输入光束在光路第一个元件处复曲率半径的实部和虚部。

如果你把 M² 参数设置为不同于 1 的值，则假定实部和虚部对应于伪高斯光束的复曲率半径。利用该参数和给定的 M² 值计算等效高斯光束的复参数。然后由光路矩阵对它进行变换。

.. note::

  当你通过复曲率半径设置输入光束时，应当记住复曲率半径倒数的虚部。因此，复曲率半径的整体取值取决于波长。如果你改变光路的工作波长，那么同一个复曲率半径值就会对应于另一束光。
