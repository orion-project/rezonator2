自定义参数
=================

:menuselection:`Element --> Properties`

自定义参数允许你在元件的标准内置参数之外，用附加的用户定义参数来扩展元件。当你需要跟踪或计算你的光学系统特有的附加属性时，这很有用。自定义参数可以创建、编辑和删除。它们的行为与常规元件参数相同，并且可以：

- 关联到 :ref:`全局参数 <params_window>`
- 在 :doc:`自定义函数 <custom_funcs>` 中被引用
- 使用 :doc:`调节工具 <adjust>` 进行调节

自定义参数功能通过位于 :doc:`elem_props` 对话框中 :guilabel:`Parameters` 选项卡右上角的一个菜单按钮访问。该菜单提供管理自定义参数和参数预置的命令。

  .. image:: img/custom_params.png

.. --------------------------------------------------------------------------

管理自定义参数
------------------------

.. _custom_params_create:

创建新参数
~~~~~~~~~~~~~~~~~~~~

:menuselection:`Parameters menu --> Add Parameter...`

创建新的自定义参数时，你必须指定参数属性：

- **Label** —— 在公式和表格中使用的简短标识符（例如 ``Pth``、``alpha``）
- **Name** —— 完整的描述性名称（例如 “Threshold power”、“Brewster angle”），当参数被选中时显示在 Element Properties 对话框中
- **Description** —— 参数的可选详细说明，当参数被选中时显示在 Element Properties 对话框中
- **Dimension** —— 物理量纲（例如 Linear、Angular）

可选地勾选 :guilabel:`Save as preset`，使这个参数可供复用（:ref:`见下文 <custom_params_presets>`）。

  .. image:: img/custom_params_create.png

新参数被添加到元件的参数列表中，其初始值为零，单位是该量纲最近使用的单位。然后你可以：

- 直接设置它的值
- 使用 :ref:`表达式 <elem_props_params>`
- 把它 :ref:`关联 <elem_props_link>` 到一个全局参数

.. --------------------------------------------------------------------------

.. _custom_params_edit:

编辑参数
~~~~~~~~~~~~~~

:menuselection:`Parameters menu --> Edit Parameter...`

:guilabel:`Edit Parameter` 命令仅在选中一个自定义参数时可用。内置的元件参数不能用这种方式编辑。

当你更改一个自定义参数的量纲时，系统会自动使用 SI 单位换算来转换当前值，使用新量纲最近使用的单位。例如，如果一个参数当前的值为 ``10 cm``（Linear 量纲），而你把它改为 Angular 量纲，该值会换算为 ``10 cm → 0.1 m → 0.1 rad → 5.73 deg``。该参数会被重新赋予换算后的值，单位为角度量纲的最近使用单位。

  .. warning::
    更改量纲时，确保参数仍然被恰当地使用是你的责任。如果一个参数关联到一个量纲不同的全局参数，其值将使用 SI 单位进行换算，这可能产生意想不到的结果。

.. --------------------------------------------------------------------------

.. _custom_params_remove:

删除参数
~~~~~~~~~~~~~~~~

:menuselection:`Parameters menu --> Remove Parameter...`

:guilabel:`Remove Parameter` 命令仅在选中一个自定义参数时可用。内置的元件参数不能被删除。

当你删除一个自定义参数时：

- 到全局参数的任何 :ref:`参数关联 <elem_props_link>` 都会自动被删除
- 该参数从元件中删除
- 会触发光路事件，以通知应用程序的其他部分

.. --------------------------------------------------------------------------

.. _custom_params_presets:

参数预置
-----------------

参数预置允许你快速添加常用的自定义参数，而不必每次都指定所有属性。系统提供内置预置，也支持自定义预置。自定义预置全局保存在用户的系统配置文件中，可用于所有元件和光路。

:ref:`创建新参数 <custom_params_create>` 时，勾选 :guilabel:`Save as preset` 选项，把它保存为一个可复用的预置。该参数的配置（标签、名称、说明和量纲）将在预置菜单中可供将来使用。

要从预置创建一个参数，从列表中选择一个预置（显示内置或自定义预置）。该参数会以预置的配置立即被添加。

菜单中的每个预置都有一个下拉箭头，提供附加选项，允许你修改预置配置（仅限自定义预置）或删除该预置。内置预置不能被编辑或删除，但你可以通过把它们从配置中删除来隐藏它们，以后使用 :guilabel:`Restore Default Presets` 来恢复它们。

恢复默认预置
~~~~~~~~~~~~~~~~~~~~~~~~~~

:menuselection:`Parameters menu --> Restore Default Presets...`

使用此命令清理预置集合并恢复所有内置预置。

  .. warning::
    恢复默认预置无法撤销。你所有的自定义预置 *都将丢失*。

.. --------------------------------------------------------------------------

最佳实践
--------------

- **有意义的名称** —— 选择能清楚表明参数用途的描述性别名和标签
- **一致的量纲** —— 把自定义参数关联到全局参数时，确保量纲匹配，或理解将会发生的 SI 换算
- **使用预置** —— 把常用的自定义参数保存为预置，以在你的光路之间保持一致性
- **为参数写文档** —— 使用 Name 和 Description 字段提供清晰的说明，特别是对于复杂的计算或物理含义
- **避免过度复杂化** —— 只在必要时创建自定义参数；过多的参数会让光路更难理解
