表格符号
=============

在某些情况下，同一个参数的几个值对应于表中的一个元件。

  .. image:: img/table_symbols_1.png

例如：

* 对于位于晶体边缘、介质内部和外部的点，切向平面中的光束半径以及两个平面中的波前曲率半径是不同的。

* 晶体的每一侧以及晶体中部（`z = 0`、`z = L/2` 和 `z = L`，其中 `z` 是沿光轴的坐标）的光束参数是分别计算的。

* 对于入射到曲面镜或透镜上的光束，以及反射或折射后的光束，波前曲率半径可以不同。

对于这些情况，某些元件在数据表中有不止一行对应。每一这样的行都标有一个特殊图标。

  .. image:: img/table_symbols_crystal.png

  .. image:: img/table_symbols_mirror.png

当你通过 :menuSelection:`Edit` 菜单或表的上下文菜单调用 :ref:`Copy <table_opers_copy>` 命令时，所选单元格的内容会作为文本复制到剪贴板。行图标也会以文本形式复制。

  .. image:: img/table_symbols_copy.png
