========================

.. |M^2| replace:: `M`\ :sup:`2`

:menuselection:`Tools --> Gaussian Beam Calculator`

.. Text and formulas are in the algorithm description `./calc_gauss.html`, keep these docs in sync

工具 *Gauss Beam Calculator* 在改变高斯光束的某个参数并固定其他一些参数时，计算它的一些自由参数。由于不可能让所有参数都自由，我们引入了两种固定模式，称为 *Lock waist* 和 *Lock front*。

- *Lock waist*（锁定束腰）—— 求出这样的自由参数值：当某个参数改变时，束腰 |w_0| 保持不变。
- *Lock front*（锁定波前）—— 求出这样的自由参数值：当某个参数改变时，某个轴向距离 `z` 处的波前曲率半径 `R` 和光束半径 `w` 保持不变。

二次方程有两个解，我们必须定义一种方式来指出取哪个解。因此该工具有一个附加参数——区域——可以是 *Near zone*（近场区）或 *Far zone*（远场区）。

工具栏上的前两个按钮控制锁定模式，接下来的两个按钮控制显示哪个解。

  .. image:: img/wnd_gauss_calc_w.png

光束参数
---------------

这些参数会被赋值和计算：

* `λ` —— 光的波长；它不是由其他参数计算得出的，只能赋值
* |w_0| —— 束腰半径
* |z_0| —— 瑞利长度（半共焦参数）
* |V_s| —— 远场区的光束发散角
* |M^2| —— 光束质量因子（M 平方参数）
* `z` —— 从束腰到计算或赋值波前的点的距离
* `w` —— 距束腰距离 `z` 处的光束半径
* `R` —— 距束腰距离 `z` 处的波前曲率半径
* `re(q)`、`im(q)` —— 距束腰距离 `z` 处复光束参数的实部和虚部
* `re(1/q)`、`im(1/q)` —— 距束腰距离 `z` 处倒数复光束参数的实部和虚部

计算算法
---------------------


改变束腰 |w_0|
^^^^^^^^^^^^^^^^^^

锁定束腰
~~~~~~~~~~

在给定距离 `z` 处计算光束半径 `w` 和波前曲率半径 `R`：

  .. image:: img/f_calc_gauss_w0_1.png
 
锁定波前
~~~~~~~~~~

对于指定的束腰半径 |w_0|，求出这样的距离 `z` 和光束质量 |M^2|，使得波前曲率半径保持其先前计算得到的值。

求法：将 |z_0| 从 `w(z)` 和 `R(z)` 中分别表示出来，令两个表达式相等并对 `z` 求解。

  .. image:: img/f_calc_gauss_w0_2.png

  
改变瑞利长度 |z_0|
^^^^^^^^^^^^^^^^^^^^^^^^^^^

锁定束腰
~~~~~~~~~~

在束腰半径 |w_0| 固定时，求出能给出指定 |z_0| 的光束质量参数 |M^2| 的值。

  .. image:: img/f_calc_gauss_z0_1.png

锁定波前
~~~~~~~~~~

对于指定的 |z_0|，求出这样的距离 `z` 和光束质量 |M^2|，使得波前曲率半径保持其先前计算得到的值。`+` 号对应远场区，`-` 号对应近场区。

  .. image:: img/f_calc_gauss_z0_2.png

^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

锁定束腰
~~~~~~~~~~

在束腰半径 |w_0| 固定时，求出能给出指定角度的光束质量参数 |M^2| 的值。

  .. image:: img/f_calc_gauss_Vs_1.png

锁定波前
~~~~~~~~~~

对于指定的 |V_s|，求出这样的距离 `z` 和光束质量 |M^2|，使得波前曲率半径保持其先前计算得到的值。

如何求 `z`：将 |z_0| 以 |w_0|/|V_s| 代入 `w(z)` 和 `R(z)` 的公式，从两者中分别表示出 |w_0|，令它们相等并对 `z` 求解。

改变光束质量 |M^2|
^^^^^^^^^^^^^^^^^^^^^^^^^

锁定束腰
~~~~~~~~~~

与改变束腰时相同。

  .. image:: img/f_calc_gauss_MI_1.png

锁定波前
~~~~~~~~~~

取 |M^2| 的新值，求出这样的距离 `z` 和束腰半径 |w_0|，使波前保持不变。

如何求 `z`：从 `R(z)` 的公式中表示出 |w_0|:sup:`2`，将该表达式代入 `w(z)` 的公式并对 `z` 求解。
