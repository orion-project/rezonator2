信息窗口
===================

某些函数的计算结果是一个或几个值。这样的函数称为信息函数。它们通常不需要任何参数。例如 :doc:`func_rt`、:doc:`func_reprate` 这样的函数。

信息函数的结果以文本形式呈现在小的弹出窗口中。

  .. image:: img/info_window.png

.. note::
  与 :ref:`绘图 <plot_window>` 或 :ref:`表格 <table_window>` 窗口不同，信息窗口不会保存到光路项目文件中。

命令
--------

信息窗口不在主窗口中显示菜单，因此它们的命令只能在本地窗口工具栏上使用，或通过快捷键使用。

.. --------------------------------------------------------------------------

更新
~~~~~~

:menuSelection:`F5`

该命令重新计算函数。如果当前函数已 :ref:`冻结 <func_freeze>`，则该命令不可用。

.. --------------------------------------------------------------------------

冻结
~~~~~~

:menuSelection:`Ctrl+F`

该命令冻结当前信息窗口。详情见 :doc:`func_freeze`。

.. --------------------------------------------------------------------------

冻结信息
~~~~~~~~~~~

该按钮显示一个小弹出窗口，其中显示函数被 :ref:`冻结 <func_freeze>` 时刻的元件参数值。

.. --------------------------------------------------------------------------

复制
~~~~

:menuSelection:`Ctrl+C`

该命令将所选内容作为格式化的 HTML 文本复制到剪贴板。

.. --------------------------------------------------------------------------

全部复制
~~~~~~~~

该命令将全部内容作为格式化的 HTML 文本复制到剪贴板。对于此命令，你不需要在编辑器中有选区。

.. --------------------------------------------------------------------------

帮助
~~~~

:menuSelection:`F1`

该命令显示与当前函数关联的帮助主题。

.. --------------------------------------------------------------------------

附加命令
~~~~~~~~~~~~~~~~~~~

某些函数（例如 :doc:`func_rt`）可以向工具栏添加更多特定于该类函数的按钮。它们在具体函数的帮助主题中说明。
