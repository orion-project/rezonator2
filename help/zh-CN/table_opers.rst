表格操作
================

.. --------------------------------------------------------------------------
.. --------------------------------------------------------------------------

Menu Edit
---------

.. _table_opers_copy:

复制
~~~~

该命令将所选表格单元格的内容复制到剪贴板。如果单元格中有位置图标，它们会以文本表示形式复制。见 :doc:`table_symbols`。

.. --------------------------------------------------------------------------

全选
~~~~~~~~~~

选择当前表格窗口中的所有单元格。

.. --------------------------------------------------------------------------
.. --------------------------------------------------------------------------

Menu Table
----------

.. --------------------------------------------------------------------------

更新
~~~~~~

:menuSelection:`Table --> Update (F5)`

该命令重新计算函数。如果当前函数已 :doc:`冻结<func_freeze>`，则该命令不可用。

.. --------------------------------------------------------------------------

.. _table_opers_freeze:

冻结
~~~~~~

:menuSelection:`Table --> Freeze (Ctrl+F)`

该命令冻结当前表格窗口。详情见 :doc:`func_freeze`。

.. --------------------------------------------------------------------------

.. _table_opers_show_t:

显示 T 平面
~~~~~~~~~~~~

:menuSelection:`Table --> Show T-plane`

该命令切换切向 (T) 平面结果的可见性。

  .. note::
    其中一组结果（T 平面或 S 平面的）始终保持可见。这意味着如果其中一组被隐藏，而你试图隐藏另一组，那么第一组会变为可见。

.. --------------------------------------------------------------------------

显示 S 平面
~~~~~~~~~~~~

:menuSelection:`Table --> Show S-plane`

该命令切换弧矢 (S) 平面结果的可见性。

  .. note::
    其中一组结果（T 平面或 S 平面的）始终保持可见。这意味着如果其中一组被隐藏，而你试图隐藏另一组，那么第一组会变为可见。

.. --------------------------------------------------------------------------

.. _table_opers_calc_at_medium_ends:

在介质端面处计算
~~~~~~~~~~~~~~~~~~~~~~~~

:menuSelection:`Table --> Options --> Calculate at medium ends`

在 :doc:`matrix/ElemMediaRange` 元件中计算函数。这是一个调试选项。一般而言，了解介质周围界面处的光束参数很重要。

  .. image:: img/table_calc_medium_ends.png


.. --------------------------------------------------------------------------

在空程段中计算
~~~~~~~~~~~~~~~~~~~~~~~~~

:menuSelection:`Table --> Options --> Calculate in empty spaces`

在 :doc:`matrix/ElemEmptyRange` 元件中计算函数值。这是一个调试选项。在通常情况下，空程段将一些“刚性”元件分隔开：透镜、晶体等。这些元件上的函数值将与相邻空程段的相接端面上的值相同。

  .. image:: img/table_calc_empty_spaces.png

.. --------------------------------------------------------------------------

在程段中部计算
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

:menuSelection:`Table --> Options --> Calculate in the middle of ranges`

在 :doc:`matrix/ElemEmptyRange` 和 :doc:`matrix/ElemMediaRange` 元件的中部计算函数。这是一个调试选项。

工具栏
-------

.. _table_opers_units:

工具栏包含一个带有卡尺图标的按钮，它会显示一个弹出菜单，你可以在其中选择应用于每一列值格式化的计量单位。或者，也可以在列标题上右键点击调用相同的菜单。
