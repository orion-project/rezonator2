应用程序设置：行为
==============================

:menuSelection:`Edit --> Settings --> Behavior`

.. --------------------------------------------------------------------------

.. _app_settings_edit_just _created:

编辑刚创建的元件
~~~~~~~~~~~~~~~~~~~~~~~~~

在从 :doc:`catalog` 向光路添加新元件后，自动打开 :doc:`elem_props` 对话框。

.. --------------------------------------------------------------------------

.. _app_settings_gen_labels_created:

为创建的元件生成标签
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

如果设置了该选项，则会为每个 :ref:`新建的 <elem_opers_append>` 元件自动分配一个 :ref:`标签 <elem_props_label>`。每种 :ref:`元件类型 <elem_matrs>` 都有自己的标签前缀。标签由该前缀加上一个递增的序号组成。例如，空程段的标签格式为 `L1`、`L2`……，反射镜的标签格式为 `M1`、`M2`……。

.. --------------------------------------------------------------------------

.. _app_settings_gen_labels_pasted:

为粘贴的元件生成标签
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

如果设置了该选项，则会为从剪贴板 :ref:`粘贴 <elem_opers_paste>` 的元件自动分配新的 :ref:`标签 <elem_props_label>`。这很有用，因为从另一个光路复制过来的元件，其标签可能与现有元件的标签冲突。

.. --------------------------------------------------------------------------

.. _app_settings_gen_labels_pump:

为新建泵浦生成标签
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

如果设置了该选项，则会为每个新建的 :ref:`泵浦 <pumps_window>` 自动分配一个标签。标签由前缀 `P` 加上一个递增的序号组成，例如 `P1`、`P2`。

.. --------------------------------------------------------------------------

应用程序启动后显示协议窗口
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

这是一个调试选项，可以让日志窗口在应用程序启动后自动显示。该窗口也可以通过命令 :menuSelection:`Window --> Protocol` 手动显示。

.. --------------------------------------------------------------------------

.. _app_settings_show_py_code:

在信息窗口中显示矩阵的 Python 代码
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

该选项允许在 :ref:`Element Matrices <elem_show_matrix>` 窗口中把元件矩阵显示为 NumPy 变量。这用于测试和调试。

.. --------------------------------------------------------------------------

打开光路时不加载函数窗口
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

使用该选项可以禁止加载保存在光路文件中的所有函数窗口。使用该选项可以缩短光路的加载时间，但在这种情况下，你必须重新计算所有需要的函数。如果保存的函数窗口加载时被错误中断，例如它们是在不同版本的程序中保存的，该选项也可能有用。

.. --------------------------------------------------------------------------

从在线文档打开文档，而不是本地文件
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

有人 `报告 <https://github.com/orion-project/rezonator2/issues/9>`_ 说本地文档有时无法显示。如果出现这种情况，可以改用 `在线手册 <http://rezonator.orion-project.org/help>`_。
