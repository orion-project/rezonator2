绘图窗口
===========

大多数函数的计算结果都以图形形式呈现在一个特殊的绘图窗口中。函数的名称显示在窗口的标题栏中，也显示在项目窗口的 Windows 面板上它的按钮上。例如 “Caustic”、“Stability map”。同一函数的窗口会递增编号。

  .. image:: img/plot_window.png

窗口组成
-----------------

图 (1)
~~~~~~~~

它是绘图窗口的主要部分，用于显示图形。它可以显示多个部分：坐标轴、坐标网格、图例、标题、光标、稳定性边界线（用于 :doc:`稳定性图 <func_stabmap>`）、元件边缘线（用于 :doc:`多程段焦散 <func_caustic_mr>`）。点击图的某个部分即可选中它。被选中的部分会以一种颜色和更粗的线条高亮显示，并有它自己的上下文菜单。此外，所选图形的值会显示在数据表中。

.. --------------------------------------------------------------------------

.. _plot_window_data_table:

数据表 (2)
~~~~~~~~~~~~~~~

:menuSelection:`View --> Data Table`

该表展示用于绘制所选图形的一批值。如果你需要复制一部分值，该表会很有用；使用该表的上下文菜单即可。该表不可编辑。显示值的精度由 :ref:`应用设置 <app_settings_format_precision>` 控制。

.. --------------------------------------------------------------------------

附加参数 (3)
~~~~~~~~~~~~~~~~~~~~~~~~~~

:menuSelection:`View --> Function Params`

某些函数，例如 :doc:`func_caustic`，有一组附加参数，用于控制应在图上显示什么。这些参数在具体函数的文档中“附加参数”一节里说明。

.. --------------------------------------------------------------------------

.. _plot_window_spec_points:

特殊点 (4)
~~~~~~~~~~~~~~~~~~~

:menuSelection:`View --> Special Points`

该面板显示一组对当前函数而言多少有些值得注意的值。当此面板可见且函数被重新计算时，特殊点会自动计算。面板中显示的内容在具体函数的文档中“特殊点”一节里说明。显示值的精度由 :ref:`应用设置 <app_settings_format_precision>` 控制。

.. --------------------------------------------------------------------------

光标 (5)
~~~~~~~~~~

:menuSelection:`View --> Cursor`

光标是一条或两条交叉线，可以用鼠标拖动。光标面板显示光标交叉点的坐标，以及在光标所在点计算出的函数值（在 T 和 S 平面中）。见 :doc:`plot_cursor`。

.. --------------------------------------------------------------------------

状态栏 (6)
~~~~~~~~~~~~~~~

状态栏显示：

- X 轴和 Y 轴的计量单位。右键点击标签即可更改单位。或者使用相应坐标轴的上下文菜单。
- 所选图形中的点数。点击图上的一个图形即可选中它。
- 取决于具体函数类型的附加信息或上下文消息。
